# Django + DaisyUI Template

> A Django project template styled with DaisyUI (Tailwind CSS components).

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## Features

- Django project scaffold with a reusable app layout.
- DaisyUI components on top of Tailwind CSS.
- Ready-made base template, navbar and cards.

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Django |
| Styling | DaisyUI, Tailwind CSS |

## Quick Start

```bash
git clone https://github.com/dastonbek8747/django-daisyui-template.git
cd django-daisyui-template
python -m venv .venv && source .venv/bin/activate
pip install django
python manage.py migrate
python manage.py runserver
```

## Note

The committed `node_modules/` folder has been removed from version control. Reinstall front-end dependencies with `npm install` if you rebuild the CSS.
